# Vela brand assets

- `vela-logo.png`: transparent horizontal logo, blue sail monogram with a navy lowercase wordmark. Use on light backgrounds.
- `vela-mark.png`: transparent square monogram for avatars and small brand placements.

Both repositories use identical files. Keep the proportions and clear space around the logo.

Palette: cobalt blue `#208AEF`, navy `#0B1830`.

Generated with the built-in imagegen tool. These are PNG assets, not vector masters.

## Generation prompt

Create a professional distinctive logo for Vela, a contactless peer-to-peer payments app on Stellar. One horizontal lockup: an abstract V formed from two crisp sail shapes on the left, lowercase “vela” on the right in modern rounded sans typography. Cobalt blue and dark navy. Transparent background, generous padding, flat clean artwork, no mockup or extra symbols.

## Mark prompt

Preserve the two blue sail shapes of the V monogram, remove the wordmark, and center the monogram on a square transparent canvas with generous padding.

## Mobile launcher assets

- `vela-app-icon.png`: opaque 1024 × 1024 Vela launcher icon, with white padding for adaptive icon masks. Used on iOS and Android.
- `vela-favicon.png`: 64 × 64 export for web.
- `vela-mark.png`: splash image displayed on white.

The launcher icon was generated with the built-in imagegen tool using the existing Vela mark: preserve the exact two blue sail shapes, center on an opaque white square, leave generous margins for Android masking, and add no text or decoration. Export padding and sizes were adjusted with sips.
